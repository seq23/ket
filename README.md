# KET

KET is a diaspora-centred micro-drama app where African diaspora leads meet other worlds.

```sh
npm ci
npm start
```

Run `npm run check` for TypeScript, catalog tests and repository validation. The **App preview** pull request check exports the Expo app and records Playwright journeys. Open the workflow run's `ket-tap-through` artifact for the videos and screenshots.
